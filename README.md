# 📊 Portal de Indicadores

O Portal de Indicadores é uma aplicação web desenvolvida para facilitar a visualização e análise rápida dos indicadores dos diversos setores da organização.

A plataforma utiliza dashboards do Power BI incorporados através de iframes, permitindo que os usuários acompanhem métricas e resultados de forma centralizada, intuitiva e acessível.

---

## 🚀 Funcionalidades

- Visualização de dashboards do Power BI.
- Navegação entre indicadores de diferentes setores.
- Interface simples e intuitiva.
- Acesso rápido às informações estratégicas.
- Centralização dos relatórios em um único portal.
- Layout responsivo para diferentes dispositivos.

---

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript
- Power BI (incorporação via iframe)
